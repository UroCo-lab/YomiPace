# 0.7.1 初回ガイドに編集説明を追加

2026-11-03。versionCode 25。説明書を兼ねる初回サンプルを10枚から16枚へ増やし、原稿を含めて新しい作成・編集操作を追加しました。説明量に合わせ、ガイドの持ち時間は5分から8分にしています。

## 追加した説明

- 画像選択、生成前の追加・削除・並び替え、PNG連番へのコピー
- アーカイブの鉛筆から「タイトル・時間指定・スライド順・原稿編集」へ進む管理ページ
- 発表時間の設定と「未定（あとで設定）」
- 画像と対応する本文・メモ・固定時間の区間を一緒に移動し、番号を更新するスライド順
- 上にスライド、下に原稿入力欄。「前へ」「次へ」で切り替え、資料名は管理ページで変更
- カーソル位置への定型文挿入、ボタンの横スクロール、内容・追加・削除・並び替え
- 保存と、未保存で閉じる際の「保存する・保存しない・キャンセル」

16枚目の削除手順、予定ペースと手動位置の説明、固定時間15秒の練習も保持しました。画像は従来の配色・文字組みを維持した1280×720のPNG、原稿はUTF-8の`##番号`形式です。

## 既存データと手動取り込み

新規データ領域の初回起動でのみ同梱ガイドを追加します。既存の資料・設定・編集済みガイドは上書きせず、削除したガイドも復活させません。更新済みの利用者は[16枚版のガイドZIP](../samples/YomiPace-welcome.zip)を「⋮」→「ZIPを開く」で取り込むと読めます。旧ガイドを残したまま別の資料として追加できます。

編集元は[samples/welcome/content.json](../samples/welcome/content.json)、説明と再生成手順は[ガイドREADME](../samples/welcome/README.md)です。描画とパッケージ化のスクリプトは枚数を固定せず、内容に追従します。既存の編集機能自体と0.7.0の配布物・PR動画は保持しています。
