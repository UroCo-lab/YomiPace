# YomiPace 操作説明

現行版は0.4.1です。0.4.0の6機能を維持し、短い横画面・スクロールつまみ・保存資料の画像連番を修正しています。

## インストール

`YomiPace-0.4.1-release.apk` を使用するAndroid端末へ転送し、端末で開いてインストールします。Androidが求める場合は、使用したファイルアプリからのインストールを端末側で許可してください。GitHub Releasesの配布版は専用の非公開鍵で署名しています。デバッグ版からの切替方法はREADMEを参照してください。

ADBでインストールする場合は、対象端末を確認してから `adb -s <端末のシリアル> install -r <APKのパス>` を実行します。この作業では接続済みの実機を変更していません。

## 資料を開く

1. メニュー「⋮」→「ZIPを開く」を押します。
2. Android標準のファイル選択画面で、ZIPのあるフォルダーに移動してZIPを選びます。
3. `time` 指定があれば持ち時間に反映されます。なければ「⋮」→「持ち時間」で分・秒を設定します。
4. 「開始」で計測を始めます。

提供された `samples/YomiPace-sample.zip` は、そのまま読み込みに使用できます。3枚の画像、7分の持ち時間、30秒・20秒の固定区間を含みます。
画像を表示できない場合は「画像を読み込めません」と「再読込」を表示します。原因となるデータを直した後は「再読込」で再表示できます。保存資料の画像番号が壊れている場合は現在の資料を保持して知らせるため、元ZIPから読み込み直してください。

## ZIPと原稿の形式

ZIP直下、または一段の親フォルダーに、`001.png` から始まる画像と `script.txt` をまとめます。PNG・JPG・JPEGに対応し、拡張子の大小は区別しません。同じ番号の重複、欠番、複数資料の混在はエラーになります。説明のないスライドにも、対応する `#番号` を書いてください。

原稿はUTF-8、BOMとLF／CRLFに対応します。

```text
time(07:00)

#1
本日は結果を説明します。

#2
こちらが結果です。
[Fig.1を説明(00:30)]
結果を補足します。
[手術動画を再生(00:20)]
[Table.2の要点を説明(00:45)]

#3
最後にまとめます。
```

`time` は原稿の先頭に1回だけ指定します。誤り・重複がある場合は行番号を知らせ、画面から持ち時間を確定できます。

固定区間はすべて `[任意の表示名(mm:ss)]` で、単独行に書きます。分は0以上、秒は00～59、括弧とコロンは半角です。0秒にも対応します。図・表・動画で処理は共通です。アプリ内で動画を再生する機能はありません。

画像は最大200枚、1画像24MiB・40メガピクセル、原稿2MiB、展開合計256MiBです。取り込み失敗時は、それまで使用していた資料を保持します。

## 発表中の操作

- **開始**：開始・続行。もう一度押しても停止しません。
- **停止**：一時停止。経過時間・原稿位置を保持します。
- **赤い横線**：原稿領域の上から約1/3に固定。手動スクロールで、実際に読んでいる箇所を合わせます。上下配置では現在スライドと次の2枚、2カラムでは現在スライドを先頭に縦スクロールの一覧を表示します。
- **グレー**：予定上、読了時刻を迎えた文。実際に読んだことを検出するものではありません。
- **下線**：現在の予定文。固定区間中は本文の予定位置を進めません。
- **時間バー**：原稿内の固定区間。予定タイムラインで進み、スクロールや赤線への到達では始まりません。

グレー境界が赤線より下なら遅れ、赤線より上に通常色の文が残れば先行の目安です。予定は固定ペースで進み、自動スクロールはしません。持ち時間を過ぎても経過時計は進み、超過を表示します。

時計の下のシークバーで、経過時間を変更できます。触れた瞬間に時計が停止し、指を離しても停止を保ちます。「開始」でその時間から続行します。バーの範囲は0から持ち時間までで、超過している場合は現在の超過時間まで広がります。操作中は範囲を固定します。

シーク後は経過・残り・全体進捗、本文のグレー表示と下線、時間指定ブロックとスライド切替のバーを変更時刻から再計算します。巻き戻した区間は未完了へ戻ります。赤線の手動位置と、それに対応する表示スライドは保持します。シーク自体では振動せず、再開後に段落の完了時刻へ到達した場合は設定に従って振動します。

原稿左端には常時スクロールバーが表示されます。青いつまみが現在の表示範囲、隣の黄色の点が各スライドの原稿開始位置です。つまみと点は別の列に置いています。文字サイズ・画面幅・高さを変更すると、折り返し後の原稿全体に合わせて位置を計算し直します。左端のバーをタッチして表示位置を変えることもできます。

## 設定と見開き

`18pt` ボタンでフォントサイズを8～72に設定できます。内部はAndroidのspを使います。計測中も変更でき、時計と赤線に対応する文字位置を保持します。

`2s` ボタンで全スライド共通の切替時間を設定します。0秒・0.5秒等も指定できます。切替は枚数−1回で、冒頭と最後の後には追加しません。持ち時間・切替秒数の変更は時計を停止してから適用します。設定を開くだけでは停止しません。

メニュー「表示・操作設定」で次を調整できます。変更は自動保存し、次回起動時も反映します。

| 設定 | 範囲／初期値 |
|---|---|
| 持ち時間の文字サイズ | 24～72sp／44sp |
| 経過時間の文字サイズ | 24～72sp／44sp |
| 開始・停止の共通文字サイズ | 12～36sp／18sp |
| 開始・停止の共通ボタン高さ | 48～112dp／52dp。端末文字倍率で必要な場合は文字を収める高さを優先 |
| 原稿スクロールの慣性 | 0～100%／50% |

時計は文字に必要な高さを取り、横に収まらなければ持ち時間と経過時間を上下に並べます。非常に長い時間の数字は収まる大きさに調整します。操作ボタンは同じ行の他のボタンを残して横幅を分け、開始の赤・停止のグレーを保ちます。上下配置では必要に応じてプレビューを縮め、残った高さを原稿へ割り当てます。
横向きなどで高さが不足する場合は「時計欄を上下にスクロール」と表示します。時計欄だけを上下に動かして、進捗・シークバーを表示してください。開始・停止ボタンと原稿欄は画面内に残ります。

慣性0%では指を離した時点で止まり、100%では長く滑らかに流れます。中間値も連続的に調整できます。直接指で動かしている間の追従は変えず、スライド画像側のスクロールにも影響しません。

縦向きのスマートフォン・タブレットでは、上にスライド、その下に時計・操作ボタン、残りの高さに原稿を表示します。スライドは横幅に応じて16:9の高さを確保し、画面の高さの違いは主に原稿欄で吸収します。極端に短い画面では操作領域を残すためプレビューを縮小します。

横向きで利用可能幅が600dp以上の場合は左右2列になります。Foldのメイン画面として折りたたみ情報が通知され、幅600dp以上なら、縦向きでも2列を維持します。通知がない端末は通常の縦・横の判定になります。

2列ではスライドが列幅いっぱいに表示され、次のスライドはその下へ続きます。スライド側を上下にスクロールして確認してください。この操作では原稿・時計は動きません。原稿の赤線に対応するスライド番号が変わると、そのスライドが列の上端に表示されます。

中央の `⇄` で列全体を入れ替えられます。開閉・回転・画面幅変更・左右入替時も、同じ原稿文字を含む行が赤線に戻るように再配置します。

## PPTXから読み込み用ZIPを作る

メニュー「使い方」の先頭にある同名の項目で「コピー」を1回押すと、依頼例文の全文をクリップボードにコピーし、約2秒「コピーしました」と表示します。PowerPointを添付した依頼へ貼り付けてください。実際の原稿の時刻表記は、この説明の `time(07:00)`、`[説明文(00:30)]` の形式を使用します。

## クリアと時間リセット

| 操作 | 時計と進捗 | 資料と持ち時間 | 手動位置 | 表示設定 |
|---|---|---|---|---|
| 時間リセット | 0にして停止 | 保持 | 保持 | 保持 |
| クリア | 0にして停止 | 解除 | 先頭へ | 保持 |

どちらも「⋮」メニューにあります。クリアしても転送元のZIPは削除しません。次の資料に `time` がなければ、新しく持ち時間を設定します。

アプリを通常の画面再生成や開閉で作り直しても時計を保持します。OSによるプロセス終了後は、最後の保存時点の経過時間と原稿位置を復元し、停止状態で開きます。

## 原稿編集

時計を停止し、メニュー「読み上げ原稿の編集」を開きます。本文と #番号・time・説明区間を編集して「保存」を押してください。原稿の不備は行番号等で表示し、元の原稿を保持します。未保存で閉じると変更の破棄を確認します。

本文だけの変更では画面の持ち時間を保持し、timeを明示的に変更した場合は反映します。経過時間を保持して予定配分を更新します。同じ文を特定できない場合は現在スライドの先頭へ戻ります。元ZIPは変更しません。

## アーカイブとゴミ箱

メニュー「アーカイブ」に取り込んだ資料が並びます。「開く」で時計を0にして資料を表示し、鉛筆でその資料の原稿を編集できます。ゴミ箱ボタンを押すとゴミ箱リストへ移動します。

メニュー「ゴミ箱」では「復元」でアーカイブへ戻せます。さらにゴミ箱ボタンを押し、確認画面で「完全に削除」を選ぶと、アプリ内の元ZIP・画像・編集原稿を削除します。転送元のZIPは削除しません。「クリア」ではアーカイブを保持します。

旧版に残っている表示資料は引き継ぎます。旧版で消えた資料は再読込が必要です。これから取り込むZIPは元ファイルごと端末内のアプリ専用領域へ保存します。

## グレー表示のバイブ

メニュー「グレー表示のバイブ」でオン／オフと「弱・中・強」を設定して「適用」を押します。初期値はオフです。

予定ペースで、改行で区切った本文段落の全体がグレーになった時点で振動します。赤線・手動スクロールでは振動しません。停止中、開閉、文字サイズ変更、左右入替だけでも振動しません。強弱の感じ方は端末の振動機能によって異なります。
