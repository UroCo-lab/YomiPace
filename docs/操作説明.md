# YomiPace 操作説明

現行版は0.8.0です。アーカイブの鉛筆と、新規画像からの生成後に、4ボタンの管理ページを開きます。原稿のページ区切りは `##番号`、読まないメモは行頭の `**` です。[0.8.0の配布ページ](https://github.com/UroCo-lab/YomiPace/releases/tag/v0.8.0)から取得できます。

## インストール

更新用の `YomiPace-0.8.0-release.apk` を使用するAndroid端末へ転送し、端末で開いてインストールします。公開済みの版は配布ページから取得できます。Androidが求める場合は、使用したファイルアプリからのインストールを端末側で許可してください。更新用APKは従来と同じ専用の非公開鍵で署名しています。デバッグ版からの切替方法はREADMEを参照してください。

ADBでインストールする場合は、対象端末を確認してから `adb -s <端末のシリアル> install -r <APKのパス>` を実行します。この作業では接続済みの実機を変更していません。

## 資料を開く

### 初回起動のはじめてガイド（0.8.0）

新規インストール後に初めて起動すると、アプリ内に同梱した19枚・9分30秒の説明資料をアーカイブへ保存し、停止状態で開きます。ネット接続やファイル選択は不要です。「開始」を押し、原稿を指で動かして操作を試してください。10〜18枚目には原稿作成・編集・複製・ZIP共有、最後の19枚目には削除手順があります。

不要になったら「停止」→「⋮」→「アーカイブ」→「YomiPace はじめてガイド（19枚）」のゴミ箱ボタンで移動します。完全に削除する場合は「ゴミ箱」→同じ資料のゴミ箱ボタン→確認画面の「完全に削除」です。完全削除前なら「復元」で戻せます。「クリア」は表示解除だけです。いずれもサンプルを自動で開き直したり、再作成したりしません。

既存の資料や設定がある版から更新した場合は、サンプルを自動追加しません。更新した19枚版を読む場合は、[はじめてガイドZIP](../samples/YomiPace-welcome.zip) を手動で取り込めます。従来の3枚・7分のサンプルも引き続き使用できます。

### 自分のZIPを開く

1. メニュー「⋮」→「ZIPを開く」を押します。
2. Android標準のファイル選択画面で、ZIPのあるフォルダーに移動してZIPを選びます。
3. `time` 指定があれば持ち時間に反映されます。なければ「⋮」→「持ち時間」で分・秒を設定します。
4. 「開始」で計測を始めます。

提供された `samples/YomiPace-sample.zip` は、そのまま読み込みに使用できます。3枚の画像、7分の持ち時間、30秒・20秒の固定区間を含みます。
画像を表示できない場合は「画像を読み込めません」と「再読込」を表示します。原因となるデータを直した後は「再読込」で再表示できます。保存資料の画像番号が壊れている場合は現在の資料を保持して知らせるため、元ZIPから読み込み直してください。

## 画像から読み上げ原稿を作成する

1. 時計を停止し、「⋮」→「読み上げ原稿作成」を開きます。
2. 「画像選択」でスクリーンショット等を選びます。選択順を要求して取り込みますが、端末の選択画面によっては選択順に対応しないため、次の画面で順番を確認してください。
3. ↑・↓で並び替え、「削除」で除外、「画像を追加」で末尾へ追加し、「生成」を押します。元画像を消したり変更したりせず、アプリ内にPNG連番と空の原稿を作ります。
4. 管理ページから「タイトル」「時間指定」「スライド編集」「原稿編集」を選びます。タイトルと発表時間は後からも編集できます。時間は分・秒、または「未定（あとで設定）」です。
5. 「原稿編集」で、上のスライドを見ながら下の入力欄に書きます。「前へ」「次へ」でページを切り替えます。`##番号` は自動で付くので、入力欄には本文だけを記入します。資料名の入力欄はこの画面には表示しません。
6. 間の文字列ボタンでカーソル位置へ挿入します。選択範囲があれば置き換えます。横スクロールでき、初期値は `[任意の文字列(mm:ss)]` と `**コメントアウト`。右端の「⋮」で内容・追加・削除・順序を編集し、「適用」でボタン設定を保存します。
7. 時間区間は単独行に置き、`mm:ss` を `00:30` 等の有効な時間へ書き換えます。読まないメモは行頭に `**` を置きます。空の原稿ページも下書き保存できます。
8. 各ページの「管理へ戻る」で管理ページへ戻れます。変更は「保存」でまとめて確定します。未保存で「閉じる」を押すと、保存する／保存しない／キャンセルを選べます。保存失敗時は編集画面に残ります。

生成済みの画像と最後に保存した原稿はアーカイブに残ります。現在表示中の資料は自動で切り替えません。アーカイブから作成した資料を開いて練習を始めます。未定の時間は管理ページの「時間指定」または発表画面の「持ち時間」から後で設定できます。画像は最大200枚・各24MiB/40MP、出力画像合計256MiB、原稿UTF-8で2MiBが上限です。未保存の変更はプロセス終了には復元しません。

## アーカイブの資料をスライド付きで編集する

編集前に「⋮」→「アーカイブ」→資料の「複製」を押し、複製した資料の鉛筆から編集するのがおすすめです。元の画像と原稿をバックアップとして残せます。鉛筆ボタンで管理ページを開きます。ZIPから取り込んだ既存資料や旧原稿も利用できます。

「スライド編集」は画像と対応原稿の冒頭を表示します。↑・↓で画像と原稿を一緒に動かし、新しい順番で `##1`、`##2`…を振り直します。メモ・固定の説明区間・原稿のないページも対応画像と一緒に移動します。変更は「保存」で確定し、「保存しない」で閉じれば元の順番と原稿を保持します。元ZIP・元の原稿ファイル・画像ファイルは書き換えません。

表示中の資料を編集した場合、保存後も経過時間と同じ画像の位置を保持します。別の資料を編集しても、表示中の資料や時計は切り替えません。原稿全文を直接編集したい場合は、既存のメニュー「読み上げ原稿の編集」も利用できます。

## ZIPと原稿の形式

ZIP直下、または一段の親フォルダーに、`001.png` から始まる画像と `script.txt` をまとめます。PNG・JPG・JPEGに対応し、拡張子の大小は区別しません。同じ番号の重複、欠番、複数資料の混在はエラーになります。説明のないスライドにも、対応する `##番号` を書いてください。

原稿はUTF-8、BOMとLF／CRLFに対応します。

```text
time(07:00)

##1
本日は結果を説明します。
** 質問対策：対象期間は追加資料を参照。
** 読まないメモを複数行書く場合は各行に付けます。

##2
こちらが結果です。
[Fig.1を説明(00:30)]
結果を補足します。
[手術動画を再生(00:20)]
[Table.2の要点を説明(00:45)]

##3
最後にまとめます。
```

`time` は原稿の先頭に1回だけ指定します。誤り・重複がある場合は行番号を知らせ、画面から持ち時間を確定できます。

行頭の `**` から行末までは、読み上げない補足・質問対策メモです。終了記号は付けません。行頭の空白は無視します。発表中も小さめの別色で表示し、文字数・時間配分・予定の進行判定・段落完了の振動には含めません。時間経過でグレーにならず、手動スクロールで参照できます。メモ上の赤線も所属スライドに対応します。メモ内の `##番号`・`time`・固定区間は命令として扱いません。本文途中の `**` は通常の文字です。先頭のメモは1枚目に所属し、`time` の前にも置けます。メモだけの原稿は読み上げ本文が0文字のため計測できません。

新形式では文章中や単独行の `#1` は本文です。旧資料を保持するため、行頭の空白を除いて `##` で始まる行がない原稿は、従来の `#番号` の単独行を境界として読み込みます。メモ行は判定から除きます。旧形式と新形式を混在させず、新規原稿は `##番号` に統一してください。

固定区間はすべて `[任意の表示名(mm:ss)]` で、単独行に書きます。分は0以上、秒は00～59、括弧とコロンは半角です。0秒にも対応します。図・表・動画で処理は共通です。アプリ内で動画を再生する機能はありません。

画像は最大200枚、1画像24MiB・40メガピクセル、原稿2MiB、展開合計256MiBです。取り込み失敗時は、それまで使用していた資料を保持します。

## 発表中の操作

- **開始**：開始・続行。もう一度押しても停止しません。
- **停止**：一時停止。経過時間・原稿位置を保持します。
- **赤い横線**：原稿領域の上から約1/3に固定。手動スクロールで、実際に読んでいる箇所を合わせます。上下配置では現在スライドと次の2枚、2カラムでは現在スライドを先頭に縦スクロールの一覧を表示します。
- **グレー**：予定上、読了時刻を迎えた文。実際に読んだことを検出するものではありません。
- **下線**：現在の予定文。固定区間中は本文の予定位置を進めません。
- **時間バー**：原稿内の固定区間。予定タイムラインで進み、スクロールや赤線への到達では始まりません。

グレー境界が赤線より下なら遅れ、赤線より上に通常色の文が残れば先行の目安です。予定は固定ペースで進み、自動スクロールはしません。持ち時間を過ぎても経過時計は進み、超過を表示します。

時計の下には、表示と操作を兼ねた1本の進捗バーがあります。音楽アプリのようにバーを直接タップ・ドラッグして、経過時間を戻したり先へ進めたりできます。触れた瞬間に時計が停止し、指を離しても停止を保ちます。「開始」でその時間から続行します。バーの範囲は0から持ち時間までで、超過している場合は現在の超過時間まで広がります。操作中は範囲を固定します。超過時はバーが注意色になります。

シーク後は経過・残り・全体進捗、本文のグレー表示と下線、時間指定ブロックとスライド切替のバーを変更時刻から再計算します。巻き戻した区間は未完了へ戻ります。赤線の手動位置と、それに対応する表示スライドは保持します。シーク自体では振動せず、再開後に段落の完了時刻へ到達した場合は設定に従って振動します。

原稿スクロールバーは初期設定では左端に表示します。メニュー「表示・操作設定」で右・左・なしへ変更できます。青いつまみが現在の表示範囲、バー内の黄色の点が各スライドの原稿開始位置です。点と縁取りをバーの内側に収め、青いつまみの上に重ねて表示します。文字サイズ・画面幅・高さを変更すると、折り返し後の原稿全体に合わせて位置を計算し直します。表示中のバーをタッチして表示位置を変えることもできます。

## 設定と見開き

`18pt` ボタンでフォントサイズを8～72に設定できます。内部はAndroidのspを使います。計測中も変更でき、時計と赤線に対応する文字位置を保持します。

`2s` ボタンで全スライド共通の切替時間を設定します。0秒・0.5秒等も指定できます。切替は枚数−1回で、冒頭と最後の後には追加しません。持ち時間・切替秒数の変更は時計を停止してから適用します。設定を開くだけでは停止しません。

メニュー「表示・操作設定」で次を調整できます。変更は自動保存し、次回起動時も反映します。

| 設定 | 範囲／初期値 |
|---|---|
| 原稿スクロールバー | 右・左・なし／左 |
| 持ち時間の文字サイズ | 24～72sp／44sp |
| 経過時間の文字サイズ | 24～72sp／44sp |
| 残り時間の文字サイズ | 24～72sp／44sp |
| 持ち時間・経過時間・残り時間の色 | 各項目で自動・基本色・#RRGGBB／自動 |
| 計測中のスリープ禁止 | ON／OFF、初期ON |
| 開始・停止の共通文字サイズ | 12～36sp／18sp |
| 開始・停止の共通ボタン高さ | 48～112dp／52dp。端末文字倍率で必要な場合は文字を収める高さを優先 |
| 原稿スクロールの慣性 | 0～100%／50% |

持ち時間・経過時間・残り時間は横スクロールなしの横一列表示です。各欄の横幅は、項目間の余白を除いた全幅を、設定したフォントサイズの比率で配分します。12・18・30なら2:3:5です。見出しと時刻を各領域の中央に配置し、時刻の基準線も揃えます。サイズは12～72spです。1項目を大きくして他2項目の領域が狭くなると、必要に応じて他2項目の文字を自動縮小します。長い時刻などは、大きくした項目自身も領域に収まるまで縮小します。領域の比率は保存した設定値を基準にするため、表示の縮小で変わりません。設定値は上限として保存するため、画面が広がれば元のサイズに戻ります。

非常に長い時刻など、他2項目を最小にしても入らない場合だけ優先項目も必要なだけ縮小します。横スクロール・折り返し・文字の省略は行いません。残り時間は超過すると「−0:12」のように表示し、小さい超過表示と進捗バーも従来どおり注意色で表示します。

各時計の「色」を押すと、自動・赤・青・緑・オレンジ・黒・白、または6桁のカラーコード（例：#123ABC）を選べます。選択色は超過時にも維持します。「自動」ではテーマ色を使い、超過時の経過時間と残り時間は注意色になります。設定はそれぞれ独立して保存します。

「計測中のスリープ禁止」は初期ONです。ONでは「開始」後の計測中だけ画面の自動消灯を防ぎます。OFFまたは停止中は端末の通常設定に従います。計測中のON／OFF変更も直ちに反映し、設定を次回起動へ保存します。

操作ボタンは同じ行の他のボタンを残して横幅を分け、開始の赤・停止のグレーを保ちます。上下配置では必要に応じてプレビューを縮め、残った高さを原稿へ割り当てます。
横向きなどで高さが不足する場合は「時計欄を上下にスクロール」と表示します。時計欄だけを上下に動かして、進捗・シークバーを表示してください。開始・停止ボタンと原稿欄は画面内に残ります。

慣性0%では指を離した時点で止まり、100%では長く滑らかに流れます。中間値も連続的に調整できます。直接指で動かしている間の追従は変えず、スライド画像側のスクロールにも影響しません。

「原稿スクロールバー」で右・左・なしを選ぶと、青いつまみと黄色いスライド開始点が一緒に移動・非表示になります。「なし」でも原稿を指で直接スクロールできます。非表示にした側の余白は本文に使います。変更時も時計と赤線の原稿位置を保持し、設定は再起動後も復元します。左右列の入替とは独立した設定です。

縦向きのスマートフォン・タブレットでは、上にスライド、その下に時計・操作ボタン、残りの高さに原稿を表示します。スライドは横幅に応じて16:9の高さを確保し、画面の高さの違いは主に原稿欄で吸収します。極端に短い画面では操作領域を残すためプレビューを縮小します。

横向きで利用可能幅が600dp以上の場合は左右2列になります。Foldのメイン画面として折りたたみ情報が通知され、幅600dp以上なら、縦向きでも2列を維持します。通知がない端末は通常の縦・横の判定になります。

2列ではスライドが列幅いっぱいに表示され、次のスライドはその下へ続きます。スライド側を上下にスクロールして確認してください。この操作では原稿・時計は動きません。原稿の赤線に対応するスライド番号が変わると、そのスライドが列の上端に表示されます。

中央の `⇄` で列全体を入れ替えられます。開閉・回転・画面幅変更・左右入替時も、同じ原稿文字を含む行が赤線に戻るように再配置します。

## PPTXから読み込み用ZIPを作る

メニュー「使い方」の先頭にある同名の項目で「コピー」を1回押すと、依頼例文の全文をクリップボードにコピーし、約2秒「コピーしました」と表示します。PowerPointを添付した依頼へ貼り付けてください。実際の原稿の時刻表記は、この説明の `time(07:00)`、`[説明文(00:30)]` の形式を使用します。

## クリアと時間リセット

| 操作 | 時計と進捗 | 資料と持ち時間 | 手動位置 | 表示設定 |
|---|---|---|---|---|
| 時間リセット | 0にして停止 | 保持 | 保持 | 保持 |
| クリア | 0にして停止 | 解除 | 先頭へ | 保持 |

どちらも「⋮」メニューにあります。クリアしても転送元のZIPは削除しません。次の資料に `time` がなければ、新しく持ち時間を設定します。

アプリを通常の画面再生成や開閉で作り直しても時計を保持します。OSによるプロセス終了後は、最後の保存時点の経過時間と原稿位置を復元し、停止状態で開きます。

## 原稿編集

時計を停止し、メニュー「読み上げ原稿の編集」を開きます。本文と ##番号・time・説明区間を編集して「保存」を押してください。原稿の不備は行番号等で表示し、元の原稿を保持します。未保存で閉じると変更の破棄を確認します。

本文だけの変更では画面の持ち時間を保持し、timeを明示的に変更した場合は反映します。経過時間を保持して予定配分を更新します。同じ文を特定できない場合は現在スライドの先頭へ戻ります。元ZIPは変更しません。

## スライドの追加と削除

管理ページの「スライド編集」→「スライドを追加」で画像を選ぶと、選択順に末尾へ追加し、空の原稿欄を用意します。↑・↓で位置を変え、「原稿編集」で本文を入力してください。合計200枚まで扱えます。

各行の「削除」を押すと確認ダイアログを表示します。「削除する」でその画像と対応する原稿を編集内容から取り除き、「キャンセル」で中止します。最後の1枚は削除できません。残りの番号は自動で振り直します。追加・削除・並び替えは「保存」で確定し、「保存しない」で閉じれば直前の保存状態を保ちます。元画像・元ZIPは書き換えません。

## 編集前の複製とZIP共有

アーカイブの「複製」は、現在保存済みの画像・順番・原稿・発表時間を引き継ぐ独立した資料を作ります。名前に「（コピー）」が付きます。複製してからその鉛筆で編集すれば、元の資料をバックアップに残せます。複製しても発表画面の資料と経過時間は切り替えません。

「ZIP共有」は保存済みの最新内容を、001.pngからの連番PNGとUTF-8のscript.txtへまとめます。編集後の順番・追加・削除・本文・メモ・固定時間・発表時間を反映したZIPです。Androidの共有先選択画面で他アプリを選んでください。共有先側の操作が完了して初めて保存や転送が完了します。別のYomiPaceでは受け取ったZIPを「ZIPを開く」で取り込めます。

複製・共有には未保存の編集を含めません。先に保存して閉じてください。共有中も元の資料は変更しません。読まないメモも原稿に含まれます。

## アーカイブとゴミ箱

メニュー「アーカイブ」に取り込んだ資料が並びます。「開く」で時計を0にして資料を表示し、鉛筆でその資料の原稿を編集できます。ゴミ箱ボタンを押すとゴミ箱リストへ移動します。

メニュー「ゴミ箱」では「復元」でアーカイブへ戻せます。さらにゴミ箱ボタンを押し、確認画面で「完全に削除」を選ぶと、アプリ内の元ZIP・画像・編集原稿を削除します。転送元のZIPは削除しません。「クリア」ではアーカイブを保持します。

旧版に残っている表示資料は引き継ぎます。旧版で消えた資料は再読込が必要です。これから取り込むZIPは元ファイルごと端末内のアプリ専用領域へ保存します。

## グレー表示のバイブ

メニュー「グレー表示のバイブ」でオン／オフと「弱・中・強」を設定して「適用」を押します。初期値はON・中です。0.5.0への最初の更新時も一度ON・中へ設定し、以降に選んだON／OFFと強さを保存します。

予定ペースで、改行で区切った本文段落の全体がグレーになった時点で振動します。赤線・手動スクロールでは振動しません。停止中、開閉、文字サイズ変更、左右入替だけでも振動しません。強弱の感じ方は端末の振動機能によって異なります。



## 設定画面のスクロール案内

「表示・操作設定」の内容が画面に収まらない場合、右端にスクロール位置を示すバーを常時表示します。つまみの長さは表示中の範囲に対応します。本文を指でスクロールするほか、つまみのドラッグやバーのタップでも移動できます。

下に続きがある場合は下端を薄い影で暗くし「↓ 下に続き」、上へ戻れる場合は上端に「↑ 上に続き」を表示します。その方向の端に到達すると影と案内が消えます。「閉じる」はスクロール領域の外に固定しています。

## 実験：DOPAGAKIモード（0.5.5）

「⋮」→「実験」→「DOPAGAKIモード」で切り替えます。初期はOFFです。音は鳴らさず、タッチ・スクロールで火花とコンボ、予定上の段落完了でバーストを表示します。演出の進行は経過時間／持ち時間を基準にし、原稿の手動位置では変わりません。

| 発表の進行 | 演出 |
|---|---|
| 前半 | SPARK。小さな火花から静かに開始し、時間と設定に応じて増加 |
| 50%以上 | BOOST。粒子と集中線が増加 |
| 75%以上 | FEVER!。広がるリングと速い振動ビート |
| 90%以上 | LIMIT BREAK。濃い集中線と多量の紙吹雪 |
| 97%以上 | CLIMAX!!。終盤の最大演出 |
| 超過 | OVER DRIVE。最大付近の熱量を維持 |

時計3項目はエフェクトを重ねません。原稿欄には動く背景を描き、本文・予定読了のグレー・下線・赤線・原稿バーはその後ろに隠れない順序で最前面に描きます。文字の暗い下地と縁取りで、背景の色に関係なく読むことができます。原稿の文字サイズ・論理位置は演出で変わりません。時計欄全体と進捗バーには演出を重ねません。スライド上は最大12%の薄い装飾だけで、花火・大きな文字・暗幕は重ねません。ボタンや周辺は引き続き装飾します。Foldの2列・左右入替に追従します。

古き良きインターネットの雰囲気として、文字ごとに色の違うWELCOME、NEW!!、星柄、立体的な枠、流れる電光テロップ、熱量の数字カウンター、目が光り手を振るオリジナルの招き猫を追加しました。熱量カウンターは遊びの演出で、アクセス数の計測ではありません。元サイトの画像・GIF・音源は使用していません。

タッチ・8コンボの追加花火・段落完了の三方向バーストも、現在の時間と設定の強さに従います。序盤の連打だけで最大演出にはなりません。

「演出の強さ」は30～100%（10%刻み、初期100%）で終盤の最大の派手さを調整します。「盛り上がりカーブ」は「後半型」「標準（直線）」「前半型」（初期標準）です。どの設定でも開始時は控えめです。時間を巻き戻すと花火・コンボ・拍をリセットし、再開後もその時間の強さから盛り上がります。原稿の手動スクロールでは段階を変えません。

「演出のシェード」は0～100%（10%刻み、初期0%）。0%でネオンの原色をそのまま表示し、大きくするほど演出だけを暗くします。盛り上がりを表現する全体透明度を廃止し、粒子や線の数・大きさ・速度で段階を付けます。原稿の文字下地・縁取りと、時計・進捗バーの保護はこの設定で弱めません。スライド上の装飾も最大12%を維持します。

招き猫を画面下側の左右へ描き、文字と赤線を最前面へ保ちます。個人ホームページ風のキリ番カウンター・工事中・相互リンク募集中・WebRing・足あとBBS・Sorry, Japanese only!・推奨800x600を追加。カウンターは経過時間に応じた遊びの数字で、実際のアクセス数ではありません。リンクやBBSは演出表示で、外部サービスへの送信や接続はしません。

「演出の振動」は専用のON/OFF（初期ON）で、「グレー表示のバイブ」と独立します。「振動ビート」（初期ON）も個別に選べます。ビートONでは72→180 BPMで加速し、4拍ごとに強拍、各拍は12～34msの短い単発振動です。タッチや段落の振動を重ねずリズムを保ちます。ビートOFFではタッチ・段落完了の振動だけになります。演出の振動OFFで両方止まります。すべての設定は再起動後も保持します。既存の振動OFFは今回の更新でONに戻しません。

停止・シークで自動演出とビートは止まります。「開始」でその時間から再開します。停止中のタッチは小さな火花と短い振動だけです。メニュー・設定画面・バックグラウンドでは休止し、復帰時に過去の拍をまとめて鳴らしません。アプリは無音です。

### 旧版のバイブOFFについて

0.4.8は未設定時だけONにしていたため、旧版で保存されたOFFが残ることがありました。0.5.0は最初の起動で一度ON・中へ設定します。その後に「グレー表示のバイブ」で選んだOFFや強さは再起動しても維持します。

### タッチ・クラッカー・風船・打ち上げ花火（0.5.4）

触った場所で火花が弾け、短い間隔を空けてクラッカーと風船が飛び出します。原稿欄も画面座標と対応させ、文字の背後で同じ位置に反応します。後半は上昇して開く花火、一定のビートで自動の風船・花火も加わります。序盤は小さく少なく、終盤は大きく多くなります。シェード設定を反映し、スライド上は最大12%、時計・進捗バーは保護します。停止・巻き戻し・モードOFF・バックグラウンドで途中の風船と花火も消えます。アプリは無音です。

標準のカーブは直線で、どのカーブも予定時間に設定した強さへ到達します。100%なら予定時間で最大、超過後は最大を維持します。猫は画面下側の両端でビートに合わせてジャンプ・手招きし、75%以降は目のビームが伸びます。原稿の文字・赤線は猫とビームより前に描きます。

### 自然再生の演出更新（0.5.5修正）

0.5.4以前には、自然な時間経過では演出の強さが更新されず、シーク等をするとその時刻の強さへ変わる不具合がありました。0.5.5は時計の更新を画面側で監視し、計測中も継続して演出へ反映します。シーク操作をせずに予定時間へ進んでも最大値へ到達します。
