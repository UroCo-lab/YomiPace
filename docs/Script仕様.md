# Script仕様（0.5.7）

この文書はページ区切りと読み上げ対象外メモの現行仕様です。旧仕様の `#番号` に関する記載より優先します。元の参考仕様・旧配布物は保存します。

```text
time(04:00)

##1
これから結果を説明します。本文中の#1はそのまま書けます。
** 質問対策：対象期間は追加資料を参照。
** 複数行のメモは各行に**を付けます。

##2
こちらが患者背景です。
[図を説明(00:30)]
```

|記法|意味|
|---|---|
|`##1`、`##2`…の単独行|ページ区切り。1から画像枚数まで順番に指定。本文のないページにも必要。|
|行頭の `**`|その行の末尾まで読み上げ対象外メモ。終了記号は不要。複数行なら各行に付ける。|
|`time(mm:ss)`|先頭に1回の持ち時間指定。メモと空行は先頭判定から除く。|
|`[表示名(mm:ss)]` の単独行|時間を確保する説明区間。|

UTF-8（BOM可）、LF・CRLF・CR改行に対応し、行頭・行末の空白を除いて判定します。半角の記号を使用します。本文途中の `**` は普通の文字で、行末に終了記号を書く必要はありません。

メモは原稿中に、小さめの文字・別色・背景を付けて表示します。文字数、本文への予定時間配分、予定の文の下線・グレー化、段落完了の振動から除外します。メモ内の `##`、`time`、固定時間区間を解析しません。メモだけの原稿は本文0文字として計測できません。

メモは直前のページに所属し、最初のページ区切りより前なら1ページ目に所属します。手動スクロール中にメモが赤線上に来ても所属ページを表示し、時計や予定配分を動かしません。文字サイズ変更・画面再配置・保存復元では、メモもIDと文字オフセットによる論理位置を保持します。編集によって同じメモを特定できない場合は現行の復元ルールに従い、現在ページの先頭へ戻します。

互換性：メモ以外に、先頭空白を除いて `##` で始まる行が一つでもある場合は新形式です。新形式の `#1` は単独行でも本文です。それ以外の旧原稿では、従来の `#1`、`#2`…の単独行を境界として読み込みます。新旧形式を混在させず、新規作成時は全て `##番号` に統一します。元ZIPと既存の保存原稿は自動書換えしません。

メニューの「使い方」にあるAI向けZIP作成プロンプト、ヘルプ、編集画面の案内、公開サンプル、初回ガイドは同じ記法を使用します。AIには明示されたメモだけをコメント化させ、不明な区別やノート欠落を確認させます。
