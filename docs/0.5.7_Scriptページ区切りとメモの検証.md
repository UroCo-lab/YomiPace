# 0.5.7 Scriptページ区切りとメモの検証

2026-11-03。0.5.7／versionCode 21。配布用APKは従来と同じ鍵で署名しています。

ページ区切りを `##1`、`##2`…の単独行にし、行頭 `**` を読まないメモにしました。メモは小さめの別色と背景で表示し、文字数・時間配分・予定の文の進行・段落完了の振動から除外します。本文途中の `**`、新形式における `#1` は本文です。

旧原稿は互換モードで読み込みます。既存ZIP・保存資料を自動変換せず、新しいページ区切りがある原稿では旧 `#番号` を制御命令として解釈しません。詳細は [Script仕様](Script仕様.md) を参照してください。

AI向けZIP作成プロンプト、アプリ内ヘルプ、編集画面の案内、README、操作説明、3枚のサンプル・テスト用ZIP、初回10枚ガイドの原稿と生成スクリプトを更新しました。メモは明示された箇所だけを使い、AIが本文を勝手にコメント化・補足を創作しない指示を追加しています。時間書式も `mm:ss` と具体例へ統一しました。

初回ガイドの新原稿は新規データ領域か手動取り込み時に使用します。既存資料の置換・削除したガイドの再作成は行いません。サンプル画像の全バイトと旧配布物のハッシュの保持を確認しました。
