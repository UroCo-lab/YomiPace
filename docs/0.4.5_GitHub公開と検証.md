# 0.4.5 GitHub公開と検証

2026-11-02（日本時間）。0.4.2～0.4.5の変更をまとめてソースと配布APKへ反映しました。

- [ソースコード](https://github.com/UroCo-lab/YomiPace)
- [0.4.5 配布ページ](https://github.com/UroCo-lab/YomiPace/releases/tag/v0.4.5)
- [機能と開発時の検証結果](0.4.5_時計領域の比率配分と検証.md)

## 変更内容

- 原稿スクロールバーを右・左・なしから選択して保存できます。
- 持ち時間・経過時間・残り時間を横一列に表示します。各色とフォントサイズを保存できます。
- 時計欄の全幅を設定フォントサイズの比率で配分し、見出しと時刻を中央へ配置します。12・18・30spなら領域幅は2:3:5です。収まらない文字は自動縮小します。
- 計測中の画面消灯防止をオン・オフできます。初期値はオンです。

## 公開前の照合

## 検証範囲

開発中には画像待機の断続的タイムアウトが発生し、最終全件実行では成功しました。根本原因の解消は断定していません。実機での上書き更新・Fold開閉・振動・消灯防止はNOT_RUNです。GitHub Actionsは公開時のpushで実行され、その結果は [Actions](https://github.com/UroCo-lab/YomiPace/actions) から確認できます。この記録のローカル検証結果とは別に扱ってください。
