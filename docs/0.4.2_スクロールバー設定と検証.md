# 0.4.2 原稿スクロールバーの表示設定

2026-11-02。versionCode 7。原稿スクロールバーを「右・左・なし」から選べるようにしました。

## 操作

「⋮」→「表示・操作設定」→「原稿スクロールバー」で選びます。初期値は従来どおり「左」です。変更は自動保存し、次回起動にも反映します。

- 右・左：青いつまみと黄色いスライド開始点を指定側へ表示します。つまみと点は別の列を保ちます。
- なし：つまみと黄色い点を表示せず、バー用の余白を本文に戻します。原稿は指で直接スクロールできます。隠れたバーを誤ってタッチする状態にはなりません。
- 変更時も時計・予定タイムライン・赤線の論理文字位置を保持します。左右列の入替とは独立した設定です。
- 文字サイズ・画面幅が変わると原稿と黄色い点を再計算します。右側でもつまみを掴んだ位置との差分を保持し、触れただけでは原稿を移動しません。

## 実装と検証対象

`ReaderScrollbarPosition.kt` に保存値と表示名を定義し、未設定・不明な保存値は左へ戻します。`AppViewModel` で保持・保存し、設定画面とネイティブ原稿Viewへ渡します。原稿Viewは表示側に応じて本文余白・つまみ・点・タッチ領域を変更します。

追加したテストは次の3件です。

| テスト | 確認内容 |
|---|---|
| `scrollbarSidesAndHiddenModeKeepAnchorAndUseTheCorrectEdge` | 明暗両テーマで左右の黄色い点の画素、つまみ位置、つまみを掴んだ際の位置保持、非表示時の端タッチ、再折り返し後の原稿位置 |
| `scrollbarChoicePersistsAndOldOrInvalidSettingsDefaultToLeft` | 3設定の再起動相当の復元、未設定と不明値の既定値 |
| `scrollbarSettingWorksAcrossFoldSwapAndReaderFontChanges` | メニュー操作、選択状態、計測中の設定変更、Fold相当の開閉、左右入替、文字サイズ変更、時計・原稿位置の保持 |

公開用の架空サンプルを使用し、実際の発表資料は使用していません。
