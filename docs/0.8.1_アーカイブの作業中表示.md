# 0.8.1 アーカイブの作業中表示

複製やZIP共有の準備中に、アーカイブ画面の下へ回転するインジケーターと「複製を作成中…」「共有用ZIPを作成中…」を表示します。「完了までお待ちください。」も添え、一覧をスクロールしても見える位置に固定します。所要時間を計測していないため、進捗率は表示しません。

実際の非同期処理を開始する時点で表示し、保存内容の読み取り・画像処理・ZIP作成・一覧の更新まで維持します。ZIP共有は共有先選択画面を開くまでの表示で、他アプリの転送状況を示すものではありません。成功・失敗のどちらでも処理が終われば消え、各ボタンを再び操作できます。

処理中は一覧内の操作に加え、上部のゴミ箱／アーカイブ切り替えと「閉じる」も無効にします。連打による重複処理は引き続き防ぎます。読み上げ機能には、回転アニメーションを繰り返し通知せず、操作名の変更を通知します。

画像・原稿・ZIPの保存／複製／共有処理、既存の資料・設定・初回ガイドは従来どおりです。
