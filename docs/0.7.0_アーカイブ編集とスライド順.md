# 0.7.0 アーカイブ編集とスライド順

2026-11-03。versionCode 24。アーカイブからの編集と画像・原稿の並び替えに対応した公開版です。[0.7.0のRelease](https://github.com/UroCo-lab/YomiPace/releases/tag/v0.7.0)から取得できます。

## 画面の流れ

アーカイブの鉛筆ボタンで、選んだ資料の管理ページを開きます。新しく画像を生成した場合も同じ管理ページへ進みます。管理ページには「タイトル」「時間指定」「スライド順」「原稿編集」の4ボタンを配置しました。

タイトルは専用ページで編集します。スライドを見ながら本文を書く原稿編集画面には資料名の入力欄を表示しません。原稿編集・時間指定・並び替えの各ページから「管理へ戻る」で管理ページへ戻れます。ページ移動だけでは変更を保存しません。

時間指定は分・秒、または未定です。「管理へ戻る」で入力内容を反映し、「保存」で確定します。入力エラーがあると修正を案内し、保存しません。未定から後日時間を設定する場合も、この管理ページの「時間指定」から行えます。発表画面での既存の持ち時間設定も利用できます。

「スライド順」はサムネイルと対応する原稿の冒頭を表示し、↑・↓で並び替えます。画像とページの原稿を一緒に移動し、表示・保存する `##1`、`##2`…を新しい順番に振り直します。本文・読まないメモ・固定の説明区間・原稿のないページも、該当する画像と一緒に移動します。本文中の文章や自由記述の数字は書き換えません。

保存はタイトル・時間・並び順・原稿をまとめて確定します。未保存で閉じる場合は、保存する／保存しない／キャンセルを選びます。保存しない場合、並び順を含めて直前の保存状態を保持します。

## 既存資料と保存の保全

画像から作った資料だけでなく、既存のZIPから取り込んだ資料や旧 `#番号` 原稿も管理ページで開けます。無変更で開く操作、またはタイトルだけの保存では元の原稿文字列をそのまま保持します。本文・時間・並び順を明示的に変更して保存する場合は、新しい `##番号` 形式の編集済み原稿として保存します。

元ZIP、元の `script.txt`、画像ファイルは書き換えません。並び順は `entry.json` の `imageOrder`（元画像番号の順列）に保存し、編集済み原稿・タイトル・時間と同じ原子的置換で確定します。読み込みでは1～画像枚数の正しい順列か検証します。この編集済みの並び順は0.7.0以降の読み込みで反映されます。

現在表示中の資料を編集した場合は、保存後も時計を停止状態・同じ経過時間に保ち、同じ画像を示すようにスライド番号と原稿の位置を移し替えます。別の資料を編集しても、現在の発表資料や時計は切り替えません。

メニューの既存の「読み上げ原稿の編集」は、原稿全体を直接編集する入口として保持しています。アーカイブの鉛筆が新しいスライド付き編集への入口です。
