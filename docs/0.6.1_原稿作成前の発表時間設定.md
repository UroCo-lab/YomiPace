# 0.6.1 原稿作成前の発表時間設定

2026-11-03。versionCode 23。画像の生成後、1枚目の原稿を編集する前に「発表時間の設定」を表示します。

「発表時間を設定する」では分・秒を入力し、「未定（あとで設定）」では時間を指定せずに始めます。「原稿編集へ」で選択を確定します。初期選択は未定です。確定が完了するまで本文の入力欄は表示しません。

具体的な時間は資料の持ち時間と、原稿先頭の `time(mm:ss)` として一括保存します。未定はメタデータをnullのまま、原稿にも時間指定を入れません。時間入力から未定へ戻したときも、入力途中の数値を採用しません。原稿画面には設定時間または「未定」を表示します。

0秒・負の分・秒60以上・数字以外・上限超過を入力した場合は設定画面に残り、修正を案内します。分は0～1000000、秒は00～59、合計は0より長い時間が必要です。保存に失敗した場合も編集へ進みません。設定画面は縦スクロールでき、下の操作ボタンを固定します。

あとから時間を決める場合は、作成・保存した資料をアーカイブから開き、メニュー「持ち時間」で設定します。既に決めた時間の変更も同じ操作です。現在の発表資料は作成処理で自動切替せず、既存の画像・原稿・設定と0.6.0の配布物を保持します。

画像コピー、文字列ボタン、保存・破棄、Foldの発表画面は0.6.0の機能を引き継ぎます。原稿作成の16テストには、時間設定・未定・未定への切替・入力エラー・後からの設定・再起動後の復元と、1枚目を表示する前の選択画面を含みます。

最終の検証結果と配布物はローカル `docs/evidence/0.6.1/` と `release/local-v0.6.1/` に記録します。実機での入力・更新・Fold操作はNOT_RUN、Dropbox同期はUNKNOWNです。GitHubへの公開は行っていません。
