# はじめてガイド

YomiPaceの操作を説明する10枚・5分のサンプルです。最終スライドにはアーカイブからゴミ箱へ移動し、完全削除する手順があります。画像は1280×720（16:9）、原稿はUTF-8です。

新規インストール後の初回起動で、自動的にアーカイブへ保存して停止状態で開きます。再起動・クリア・削除では再追加しません。既存版からの更新時は資料・設定を優先し、自動追加しません。

手動で使う場合は [読み込み用ZIP](../YomiPace-welcome.zip) を「ZIPを開く」で取り込んでください。通常の資料と同じように原稿編集、持ち時間変更、ゴミ箱への移動、復元、完全削除ができます。完全削除してもAPK同梱の資産は消えませんが、利用者のアーカイブには自動で戻りません。

## 内容

1. YomiPace／はじめてガイド
2. 予定と実際の位置
3. 開始・停止と3つの時計
4. 原稿とスライドの移動
5. グレー表示でペースを確認
6. 図の説明には固定の時間（15秒の区間を含む）
7. シークで途中から練習
8. 読みやすさと画面配置
9. 自分の資料と原稿編集
10. サンプルはアーカイブから削除できます

## 再生成

編集元は `content.json`、画像は `slides/`、読み上げ原稿は `script.txt` です。画像の再描画にはCodex付属の `@oai/artifact-tool` を利用できるNode.js環境と、日本語フォントのYu Gothicを使います。描画用ランタイムとフォントはこのリポジトリには同梱しません。既存PNGの再パッケージ化はPythonだけで実行できます。

```sh
node scripts/create_welcome.mjs
python scripts/package_welcome.py
```

Pythonの処理は標準ライブラリだけでZIPとAPK用assetsを同時に更新します。アプリを通常ビルドする際はNode.js・Pythonともに不要です。従来の3枚のサンプルとテスト用ZIPは変更しません。画像と原稿は自作で、MIT-0です。
